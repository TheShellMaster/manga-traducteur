# Consigne 01 — Présentation et état des lieux

**Interdiction de modifier du code dans cette mission.** Lecture et diagnostic seulement.

## À faire, dans l'ordre
1. Présente-toi : nom/outil, OS, `python --version`, `git --version`, peux-tu push (oui/non) ?
2. `git fetch --all && git checkout main && git pull`
3. Colle la sortie de :
   - `git log -15 --oneline --graph --all`
   - `git status`
   - `git branch -a`
4. Compte les lignes : `wc -l server.py pipeline.py` (et tout fichier .py > 300 lignes).
5. Vérifie que les fichiers ne sont pas tronqués : `python -m py_compile $(git ls-files '*.py')` — colle les erreurs.
6. `pip install -r requirements.txt` puis `pytest -q` — colle la sortie COMPLÈTE.
7. Lance le serveur 30 s et colle les erreurs de démarrage éventuelles.
8. Liste ce qui te semble cassé, sans corriger.

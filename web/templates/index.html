Bien démarrer

Manga Translator Studio traduit vos chapitres de manga directement dans les bulles, en conservant le dessin d'origine.

  1. Connectez un service de traductionOuvrez les Paramètres, onglet « Service de traduction », et collez votre clé. Une seule fois suffit.
  2. Déposez votre chapitreGlissez le fichier dans la fenêtre ou utilisez « Choisir un fichier ».
  3. Choisissez les langues puis cliquez sur TraduireLes pages se traduisent une à une et vous pouvez les lire immédiatement.
  4. Téléchargez le résultatLe chapitre traduit est enregistré dans le même format que l'original et rangé dans la Bibliothèque.

Obtenir une clé gratuite

L'application utilise un service en ligne pour lire et traduire les bulles. La solution la plus simple est Google Gemini, gratuit pour un usage personnel.

  1. Rendez-vous sur Google AI Studioaistudio.google.com/apikey et connectez-vous avec votre compte Google.
  2. Cliquez sur « Create API key »Copiez la clé affichée.
  3. Collez-la dans l'applicationParamètres, Service de traduction, Google Gemini, puis « Connecter ». Choisissez un modèle dans la liste et validez.

Votre clé reste sur votre ordinateur. Elle n'est envoyée qu'au service que vous avez choisi.

La traduction en direct

Pendant la traduction, la page en cours s'affiche avec ses trois étapes :

  • Repérage des bulles : chaque zone de texte est entourée.
  • Effacement : le texte d'origine disparaît des bulles.
  • Réécriture : la traduction est placée dans chaque bulle.

Désactivez « Suivre » pour rester sur une page pendant que les autres se traduisent. Maintenez l'image appuyée pour comparer avec l'original.

Corriger un texte

Le panneau « Textes de la page » liste chaque bulle avec sa traduction. Modifiez une phrase puis cliquez sur « Appliquer » : la page est redessinée en un instant, sans nouvelle traduction.

Apparence du texte

Dans les Paramètres, onglet « Apparence », vous pouvez choisir la police, la couleur, une taille fixe ou automatique, et la manière dont les bulles sont nettoyées. Le réglage « Automatique » convient à la plupart des mangas.

Fichiers acceptés

CBZ, CBR, ZIP, RAR, images JPG, PNG, WEBP, ou un dossier contenant des images. Le fichier traduit est rendu dans le même format.

Fermer l'application

Fermez simplement la fenêtre, ou cliquez sur le bouton d'arrêt en haut à droite. Rien ne reste actif en arrière-plan.

Questions fréquentes

Une page reste en erreur

Le service a refusé la demande (limite gratuite atteinte ou clé invalide). Attendez quelques minutes, ou cliquez sur la page puis « Retraduire la page ».

La traduction est lente

La vitesse dépend du service choisi. Les modèles marqués « rapide » dans la liste sont recommandés.

Le texte déborde de la bulle

Corrigez la phrase pour la raccourcir, ou laissez la taille sur « Automatique » dans l'onglet Apparence.

Est-ce que mes fichiers sont envoyés sur Internet ?

Seules les images des pages sont envoyées au service de traduction choisi. Les fichiers restent sur votre appareil.

Paramètres

Choisissez un service, collez votre clé, puis sélectionnez un modèle.

Auto
Le mode automatique passe en blanc sur les fonds sombres.

Quitter l'application ?

L'application sera complètement fermée. Les traductions terminées restent dans la Bibliothèque.
